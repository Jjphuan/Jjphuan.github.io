The shop

The marble table stayed.

The fiction is simple. A Petaling Jaya kopitiam kept the condensed milk, the eggs, and the loud kettle, then cleared a corner for a small grinder. Regulars still order kopi. Someone wandering in after work can ask for a yuzu cold brew and not feel out of place.

This page is a concept: a menu, the hours, a map, and a button that opens WhatsApp — so a real shop can picture the same kind of page.

Same marble table. A slower cup, if you want one.
