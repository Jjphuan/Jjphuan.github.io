# Credits

No stock photographs are used. The drawings (coffee table, map, hair studies, thumbnails, favicons) were made for this project as original SVG.

## Fonts

Loaded from [Google Fonts](https://fonts.google.com/) and used under the [SIL Open Font License](https://openfontlicense.org/):

- Instrument Serif
- Outfit
- Fraunces
- Nunito Sans
- Cormorant Garamond
- Manrope
- Bricolage Grotesque
- Source Sans 3

Chinese text falls back to a font already on the device (for example PingFang, Noto Sans CJK, Microsoft YaHei, or WenQuanYi). Those font files are not included here.

## Maps

The map on the cafe page is an original drawing. It is not OpenStreetMap or Google tile data. Links labelled "Open in Google Maps" go to a public search URL and do not use an API key.

## WhatsApp

The speech-bubble icon marks a link that opens WhatsApp. The three demo shops use `60000000000`, which is not a real line. Ree's own number is set in `ree.config.js`.
